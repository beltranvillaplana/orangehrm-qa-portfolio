# OrangeHRM QA Portfolio

Independent QA assessment of OrangeHRM, covering manual testing, functional validation, risk-based testing, and test documentation.

## Project Overview

### What is OrangeHRM?

OrangeHRM is a web-based Human Resource Management System that helps organizations manage employee information and HR processes.

The system provides modules such as employee management, user administration, leave management and other HR related operations.

## Project Objective

The main objective is to evaluate the OrangeHRM features in order to identify potential defects and assess its software quality.

How can we do that? We can read the available documentation, analyze the product and, based on that information, create test cases, test executions and test plans. This allows us to perform functional testing and selected regression checks, during which potential issues can be detected and tracked. If an issue is verified as a defect, a report will be created containing a summary, description, steps to reproduce, actual and expected results, supporting attachments such as media files and logs, and a workaround if available.

Through this independent QA assessment, I aim to demonstrate my ability to identify potential issues, prioritize testing activities, analyze software behavior, and communicate findings clearly using professional QA practices.
