## About the Project

[OrangeHRM](https://www.orangehrm.com/) is a web-based Human Resource Management System that helps organizations manage employee information and HR processes, including user administration and leave management.

This independent portfolio project aims to demonstrate my ability to:

- Analyze application behavior and identify potential risks.
- Design clear, reusable manual test cases.
- Validate functionality through functional, exploratory, and selected regression testing.
- Document execution results and communicate defects clearly.

## Testing Approach

### Risk-Based Prioritization

Testing focuses on features with the greatest potential impact and likelihood of failure. Available documentation and product exploration inform the scope and priorities.

### Test Design and Maintenance

Test cases are organized by module and functionality. They are reviewed and updated as the application evolves to keep the suite accurate, relevant, and reusable.

### Execution and Evidence

Execution results will be recorded separately from test case definitions, including test status and supporting evidence where useful.

### Defect Reporting

Potential issues will be investigated before being reported as defects. Confirmed defects will include a summary, steps to reproduce, expected and actual results, and relevant evidence. Impact and any available workaround will also be documented.
